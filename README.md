# 🧠 The React Quiz

Quiz app to test React knowledge, built to practise complex state management with `useReducer`.
Developed while following Jonas Schmedtmann's *Ultimate React Course* (Udemy).

## 🚀 Features

- **Quiz setup** – choose number of questions, difficulty level and shuffle order
- **Instant feedback** – correct and wrong answers highlighted after each question
- **Progress tracking** – progress bar, points, accuracy and answer streak
- **Countdown timer** – the quiz ends automatically when time runs out
- **Navigation** – go back, restart, and keyboard shortcuts (1–4, Enter, ←, R)
- **Results** – final score, highscore and review of missed questions
- **State management** – the whole app flow is handled with `useReducer`

## 🧰 Tech stack

React · useReducer · JSON Server (local questions API) · Create React App

## ⚙️ Getting started

```bash
npm install
npm run server   # starts the local questions API
npm start
```
